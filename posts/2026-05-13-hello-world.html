このサイトについて

2026-05-13

個人サイトを作り直した。今回採用したのは、HTML と CSS だけで構成される、極端に素朴な形式である。JavaScript は一切使わず、ビルドプロセスもなく、外部の CDN やフォントにも依存しない。テキストエディタと、ファイルを静的に置くだけのホスティングがあれば運用できる。

こうした形式を選んだ理由は単純で、長く持続させたいからだ。フレームワークは数年で陳腐化し、CDN は予告なく消える。生成されたページが、ある日突然読めなくなる経験は何度かしてきた。文章を残すなら、土台になる技術は枯れたものを選んだ方がよい。HTML と CSS は、Web そのものが続く限り読める。

装飾も最小限にした。ボーダー、シャドウ、アニメーションは使わない。フォントは OS が持っているものをそのまま使い、Web フォントの読み込みも省く。配色は二色を基本とし、ダークモードはユーザーの設定にそのまま従う。視覚的な印象より、読みやすさを優先したい。

文体は常体に揃えている。敬語のやわらかさはここでは要らない。事実と感想を、できるだけ短く、率直に並べていく。

これから何を書くかは決めていない。技術の覚書、読んだもの、考えたこと、その時々で書きたくなった話題を、ゆっくり積み上げる。更新頻度に約束はしない。RSS だけは用意してある。新しい記事はそちらで届くはずだ。
